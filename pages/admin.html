📥 Import Faculty

Creates or updates teacher accounts from the Faculty Profile template. A new email creates an account with an auto-generated password and login — write the password down from the summary below before closing this window; it cannot be shown again. A matching existing email only updates that teacher's rank, employment type, and department — their password and login are never touched. Required columns: Name, Email, Department, Employment Status, Current Faculty Rank. Department must be an organizational department — Agri, HTM, ICT, IT, or TEd — not a program code like "BSIT" or "BSTM". A "*Reference" column showing which programs sit under each department may be present for your own reading; it is ignored by this importer.

⚠️ Known effect: once faculty use these org departments, Course Assignment's "filter teachers by department" dropdown won't find them when filtered by a program code (e.g. "BSIT"). Use "All Departments" there and find the teacher by name/search until that panel is updated to match.

To also link faculty to their supervisors, include "Supervisors" and "Assignments" sheets in the same workbook (Supervisor Code + Supervisor Email + Supervisor Name on one, Supervisor Code + Faculty Email (Supervised) on the other). The faculty account must already exist. A supervisor account can be auto-created if it doesn't exist yet — you'll see an on-screen confirmation listing exactly which new supervisor accounts are about to be created (check it carefully, a typo there creates a real account with supervisor-level access) before anything is written, and any new account's one-time password will be shown in the summary below, same as new faculty accounts. A faculty can be linked to more than one supervisor if the sheet lists them twice.
