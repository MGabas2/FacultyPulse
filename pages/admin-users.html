📥 Import Students

Imports students, sections, and courses. Courses are created without a teacher assigned — the registrar can't supply that data, so it has to be set manually afterward.

Sections and courses created by this import are tagged with the semester you pick here. Create one first in Semester Management if none exist yet.

📥 Import Faculty

Creates or updates teacher accounts from the Faculty Profile template. A new email creates an account with an auto-generated password and login — write the password down from the summary below before closing this window; it cannot be shown again. A matching existing email only updates that teacher's rank, employment type, and department — their password and login are never touched. Required columns: Name, Email, Department, Employment Status, Current Faculty Rank. Department must be an organizational department — Agri, HTM, ICT, IT, or TEd — not a program code like "BSIT" or "BSTM". A "*Reference" column showing which programs sit under each department may be present for your own reading; it is ignored by this importer.
