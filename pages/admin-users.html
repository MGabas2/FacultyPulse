📥 Import Students

Imports students, sections, and course subjects. Subjects are created without a teacher assigned — the registrar can't supply that data, so it has to be set manually afterward.

Sections and course subjects created by this import are tagged with the semester you pick here. Create one first in Semester Management if none exist yet.

📧 Student Login Invites

Sends each student an email to set their first real password. Required before they can log in — login is Student ID + password + a one-time email code on new devices.
