SET / SEF Rating by Program

SET Rating is the mean of every student SET submission for faculty teaching in that program this semester (CMO No. 19 formula). SEF Rating is the mean of each faculty's latest supervisor-submitted SEF score. Click a program row to see only that program's faculty below. Programs with very few respondents will show less statistically stable averages — treat small numbers accordingly.
